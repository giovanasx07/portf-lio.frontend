# [Nome do site, ex.: Portfólio de Giovana Bastos]

Site desenvolvido como trabalho de [disciplina] (CP4) na Universidade Braz Cubas.

 **Site publicado:** https/github.com/giovanasx07/portf-lio.frontend.git](https/github.com/giovanasx07/portf-lio.frontend.git)

## Páginas

- `index.html`: apresentação e menu de navegação
- `curriculo.html`: currículo
- `formulario.html`: formulário de contato com validação
- `multimidia.html`: conteúdos de imagem, áudio e vídeo
- `graficos.html`: gráficos em SVG e Canvas

## Funcionalidades

- **Formulário com validação:** confere nome, e-mail e mensagem, e mostra o aviso na tela (sem `alert`).
- **Canvas com persistência:** o desenho feito no Canvas é salvo em `localStorage` e continua lá depois de recarregar a página.
- **Navegação:** menu e links internos entre as 5 páginas.

## Tecnologias

HTML5, CSS3 e JavaScript puro.
